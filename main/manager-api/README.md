Tài liệu này là một tài liệu phát triển. Nếu bạn cần triển khai máy chủ Xiaozhi, [bấm vào đây để xem hướng dẫn triển khai](../../README.md#%E9%83%A8%E7%BD%B2%E6%96%87%E6%A1%A3)

#Giới thiệu dự án

manager-api Dự án này được phát triển dựa trên khung SpringBoot.

Sử dụng trình soạn thảo mã để phát triển. Khi nhập dự án, chọn thư mục `manager-api` làm thư mục dự án.

#Môi trường phát triển
JDK 21
Maven 3.8+
MySQL 8.0+
Redis 5.0+
Vue 3.x
